## What's Changed

**Links between boards:** type @ in a text box, note, shape or table cell, or on the board itself, and pick another board as you type. In words it becomes a blue link; on the board it becomes a card with the board's picture. A click with Select, a tap while presenting, or Ctrl+click with any tool opens it, and a Back pill takes you straight back to where you were.

**Link to one page:** boards with several pages open up in the list so a link can go straight to "Notes › 3". If nothing has the name you typed, the list offers to make that board for you.

**Linked from:** a board that others point to says so beside its name. Sending a board over the network, or saving a copy, offers to take the boards it links to along, so the links still work on the other side. Over the network they travel inside the board itself: the other device sees a picture of each one, can untick any it does not want, and keeps the rest with one Save.

**Linked boards in PDF and SVG:** exporting a board that links to others offers to put them in the file too. In a PDF they come after it, page by page, and a click on a link jumps to the page it names. In an SVG they sit under it, and a click on a link shows that board.

**Drag and drop fixed:** PDFs, Word and PowerPoint files dropped on the desktop app import again, pictures land where you drop them, and a dropped .gazboard file opens.

**Sharing fixed:** sending several boards in a row no longer stops after the first one while the other device is still saving it, and a board turned down no longer stops the rest. A phone at the front of the class now takes boards from every student at once and asks about them one after another, where before it turned everyone away while the first question was on screen. On Android, a board that comes with its linked boards (or with big pictures) is no longer dropped on its way to the screen, and if it ever cannot be shown the phone says so and the sender is told. On the receiving side, the question no longer gets lost when another message pops up, a board that is slow to open no longer holds up the ones behind it, and when several boards arrive together only the last one opens.

**Received boards have their own folder:** everything that arrives over the network is filed in My boards under "From" and the name of the device that sent it, and the message that confirms it has an Undo that takes the whole delivery back.

**Arrows leave handwriting alone:** an arrow drawn near pen or highlighter ink no longer grabs onto it, and selected ink no longer shows arrow dots. Shapes, notes, text and pictures still hold arrows, and ink that is grouped with something else goes along with its group.

**My boards closes smoothly again:** on Android the list no longer flashes across the screen as a board opens.

**Links need 4.5 on both sides:** a board with links sent to a device on an older version shows the links as raw text there, so update both devices.
